## 1. 素性检验：从试除到 Miller-Rabin

**它是干嘛的**：素性检验回答"给一个大数 n，判断它是不是素数"。RSA 每次生成密钥都要挑两个几百位的素数，检验必须毫秒级完成；而攻击者拿到 n 之后做的第一件事也常常是"这个 n 是不是素数、有没有被人用过"。同一件事，攻防两侧都在用。

### 1.1 试除与它的极限

判断 n 有没有 2 到 $\sqrt{n}$ 之间的因子：

```python
def is_prime_trial(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True

import time
for n in (1000003, 999999999989):
    t0 = time.perf_counter()
    print("trial(%d) = %s   %.0f ms" % (n, is_prime_trial(n), (time.perf_counter() - t0) * 1000))
```

输出：

```
trial(1000003) = True   0 ms
trial(999999999989) = True   22 ms
```

12 位数毫秒级，看起来够用。但耗时随 $\sqrt{n}$ 增长，每多 6 位数字（$\sqrt{n}$ 多 3 位）耗时乘 1000：18 位数约 22 秒，30 位数约 250 天。512 比特（154 位）的 RSA 素数，$\sqrt{n}$ 有 77 位，按同一速率要 $10^{61}$ 年；2048 比特则到 $10^{292}$ 年。==试除对密码学尺度的数毫无意义==，只适合几十位以内的数和下面各检验的对照组。

### 1.2 费马检验：快，但会被卡迈克尔数骗

**它是干嘛的**：费马检验把[[09-密码学基础#2.3 费马小定理与欧拉定理|09 章 2.3]]的费马小定理反过来用。定理说"n 是素数时，对所有 a 有 $a^{n-1} \equiv 1 \pmod n$"；检验就挑几个 a，各算一次三参数 `pow`，全部同余于 1 就当 n 是素数。每个底数一次快速幂，几百位的 n 也只要毫秒。

```python
def fermat_pass(n, a):
    return pow(a, n - 1, n) == 1

import sympy
n = 561
print("561 的因子:", sympy.factorint(561))
coprime = [a for a in range(2, 561) if 561 % a != 0]
print("费马检验 561，底数 2..560 里通过的比例:",
      sum(fermat_pass(561, a) for a in coprime), "/", len(coprime))
print("费马检验 561, a=2:", fermat_pass(561, 2), " a=3:", fermat_pass(561, 3), " a=5:", fermat_pass(561, 5))
```

输出：

```
561 的因子: {3: 1, 11: 1, 17: 1}
费马检验 561，底数 2..560 里通过的比例: 319 / 553
费马检验 561, a=2: True  a=3: False  a=5: True
```

561 = 3 × 11 × 17 是合数，但与它互素的 553 个底数里有 319 个照样通过——比例还不小。而像 561 这样**对所有与它互素的底数都通过费马检验的合数**有专门的名字：==卡迈克尔数==。561 是最小的一个，且已证明卡迈克尔数有无穷多个。所以费马检验的结论不可靠：==通过不说明是素数，通不过才一定是合数==。它只能当快速筛，不能当结论。

> [!info]- 卡迈克尔数的形状
> 合数 n 是卡迈克尔数，当且仅当 n 无平方因子，且对每个素因子 p 有 p−1 整除 n−1（Korselt 判别法）。561 满足：无平方因子，560 ÷ 2、560 ÷ 10、560 ÷ 16 都整除。这类数能通过几乎所有底数的费马检验，是"只测终点"这个设计的天花板——下面 Miller-Rabin 补的就是沿途的检查。

### 1.3 Miller-Rabin：给费马检验加一道平方根复核

**它是干嘛的**：Miller-Rabin 素性检验（MR）是费马检验的加强版：除了终点 $a^{n-1} \equiv 1$，还沿途检查"平方链"的形状。费马检验被卡迈克尔数骗，是因为它只看最后一个值；MR 看的是从 $a^d$ 平方到 $a^{n-1}$ 的整条路径，绝大多数费马伪素数在这条路径上会被查出来。

先把 n−1 拆成 $d \cdot 2^r$（d 是奇数）。若 n 是素数，则对任何非零 a，从 $a^d$ 开始连平方 r 次必到 1。关键在于：素数模下 $x^2 \equiv 1$ 只有 $x \equiv \pm 1$ 两个解——所以从 $a^d$ 到 1 的路上，==变成 1 之前的那个值必须是 n−1==。一轮 MR 检验：

1. 算 $x = a^d \bmod n$；x 是 1 或 n−1，通过；
2. 否则把 x 连平方最多 r−1 次；途中出现 n−1，通过；
3. 始终不出现——n 一定是合数（出现了一个非平凡的 1 的平方根）。

```python
def miller_rabin(n, bases):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    d, r = n - 1, 0
    while d % 2 == 0:                 # n-1 = d * 2^r，d 为奇数
        d //= 2
        r += 1
    for a in bases:
        if a % n == 0:
            continue
        x = pow(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(r - 1):
            x = x * x % n
            if x == n - 1:
                break
        else:
            return False              # 平方链上没有出现 n-1 -> 必是合数
    return True

d, r = 560, 0
while d % 2 == 0:
    d //= 2
    r += 1
print("560 = %d * 2^%d" % (d, r))
print("MR(561, [2]) =", miller_rabin(561, [2]))
```

输出：

```
560 = 35 * 2^4
MR(561, [2]) = False
```

费马检验用底数 2 被骗（1.2 的输出），MR 用同一个底数 2 判出了合数。但 MR 也不是无懈可击——存在对若干固定底数全部通过 MR 的合数，叫强伪素数。最能说明问题的是这个数：

```python
import sympy
N = 3215031751
print("3215031751 =", sympy.factorint(N))
for a in (2, 3, 5, 7, 11):
    print("  单底 MR base=%2d ->" % a, "素" if miller_rabin(N, [a]) else "合",
          "  费马 base=%2d ->" % a, "素" if fermat_pass(N, a) else "合")
print("  MR 底数 [2,3,5,7]      ->", miller_rabin(N, [2, 3, 5, 7]))
print("  MR 底数 [2,3,5,7,11]   ->", miller_rabin(N, [2, 3, 5, 7, 11]))
print("  sympy.isprime          ->", sympy.isprime(N))
```

输出：

```
3215031751 = {151: 1, 751: 1, 28351: 1}
  单底 MR base= 2 -> 素   费马 base= 2 -> 素
  单底 MR base= 3 -> 素   费马 base= 3 -> 素
  单底 MR base= 5 -> 素   费马 base= 5 -> 素
  单底 MR base= 7 -> 素   费马 base= 7 -> 素
  单底 MR base=11 -> 合   费马 base=11 -> 素
  MR 底数 [2,3,5,7]      -> True
  MR 底数 [2,3,5,7,11]   -> False
  sympy.isprime          -> False
```

3215031751 = 151 × 751 × 28351 对底数 2、3、5、7 **逐个**都通过 MR（费马也全过），加一个底数 11 就判出合数。它是底数组 [2,3,5,7] 的确定性界限（见[[#1.4 确定性底数与素数生成|1.4]]）恰好压住的那个数。

错误率的定量结论（Rabin 定理）：对奇合数 n ≥ 9，随机选底数，单轮通过率不超过 1/4。独立底数测 k 轮，把合数误判成素数的概率不超过 $4^{-k}$：

- k = 20：$4^{-20} = 2^{-40} \approx 9.1 \times 10^{-13}$
- k = 40：约 $8.3 \times 10^{-25}$

==实践中 20 到 40 轮就把错误率压到"比硬件出错还低"的量级==，这就是它够用的原因——概率检验卖的不是绝对正确，是"错误率可控到可以忽略"。

### 1.4 确定性底数与素数生成

强伪素数有表可查。对固定的一小组底数，存在"小于某某全部判对"的确定性界限，每个界限对应一个恰在界限上的最小反例：

```python
spsp = [
    (2047,              [2]),
    (1373653,           [2, 3]),
    (25326001,          [2, 3, 5]),
    (3215031751,        [2, 3, 5, 7]),
    (341550071728321,   [2, 3, 5, 7, 11, 13, 17]),
]
print("已知最小强伪素数（对表中底数全部通过 MR、但均为合数）:")
for n, bases in spsp:
    ok = all(miller_rabin(n, [a]) for a in bases)
    print("  %-17d 底数 %-28s 全通过=%s  是合数=%s"
          % (n, bases, ok, not sympy.isprime(n)))
```

输出：


读法：n 小于界限时，用左边那组底数跑 MR，"是素数"的结论是**绝对**的；n 一旦到界限，这组底数恰好全部失效。==界限只对"小于"成立，写脚本时别把边界当进去==——1.3 里 3215031751 自己就是那个反例。界限再往上，把前 12 个素数（2 到 37）全测一遍可覆盖到 $10^{18}$ 以上；工程实现通常直接多测几十轮随机底数。

有了检验，生成素数就是"随机候选 + 检验"：取随机奇数，检验，不过就换下一个（素数定理保证平均试 $\ln n / 2$ 个就有命中，512 比特下约 180 个候选）。库里两个现成函数：

```python
from Crypto.Util.number import getPrime

t0 = time.perf_counter()

print("  sympy.isprime 同一数: %.2f ms" % ((time.perf_counter() - t0) * 1000))

t0 = time.perf_counter()
```

> [!info]- 强素数：一句伏笔
> **强素数**指 p−1 有大素数因子的素数。p−1 的因子越不光滑，第 4.3 节的 Pohlig-Hellman 离散对数攻击和针对 p−1 型结构的分解算法越无从下手。RSA 的随机素数一般不强求强素数（2048 比特的规模已经把那些攻击挡在门外）；Diffie-Hellman 的公开参数生成才会刻意选 p = 2q+1（q 也是素数，称安全素数）——呼应第 4.3 节。

## 2. 二次剩余：模 p 的平方根

**它是干嘛的**：二次剩余回答"在模 p 的世界里，哪些数开得平方"。实数里负数开不了方，模 p 里什么数开得了方完全另一套规则；而一旦会开方，一类密码体制（如 Rabin，密文是 $m^2 \bmod n$）的解密就只是开个根。判定"有没有根"和"根是多少"是两件事，本节各给工具。

### 2.1 定义与欧拉判据

对奇素数 p 和 $a \not\equiv 0 \pmod p$：若 $x^2 \equiv a \pmod p$ 有解，称 a 是模 p 的**二次剩余**（QR）；无解则是**非二次剩余**。把 mod 13 的平方全部列出来看形状：

```python
p = 13
squares = {}
for x in range(1, p):
    squares.setdefault(x * x % p, []).append(x)
print("mod 13 各平方数:", sorted(squares))
print("平方根表:")
for a in sorted(squares):
    print("  %2d = x^2, x = %s" % (a, squares[a]))
print("二次剩余:", sorted(squares))
print("非二次剩余:", [a for a in range(1, p) if a not in squares])
print("个数: 各 %d 个" % (len(squares)))
```

输出：

```
mod 13 各平方数: [1, 3, 4, 9, 10, 12]
平方根表:
   1 = x^2, x = [1, 12]
   3 = x^2, x = [4, 9]
   4 = x^2, x = [2, 11]
   9 = x^2, x = [3, 10]
  10 = x^2, x = [6, 7]
  12 = x^2, x = [5, 8]
二次剩余: [1, 3, 4, 9, 10, 12]
非二次剩余: [2, 5, 6, 7, 8, 11]
个数: 各 6 个
```

两个结构性质直接可见：x 与 p−x 的平方相同，所以每个根成对出现（如 $4^2 \equiv 9^2 \equiv 3$）；于是 1..p−1 里恰有一半（$(p-1)/2$ 个）是二次剩余。

有没有根不用逐个试 x，==欧拉判据==一次幂解决：

$$a^{\frac{p-1}{2}} \equiv \begin{cases} 1, & a \text{ 是二次剩余} \\ -1, & a \text{ 是非二次剩余} \end{cases} \pmod p \tag{2.1}$$

```python
for a in (1, 2, 3, 4, 9, 10, 12):
    print("a=%2d: a^6 mod 13 = %2d -> Legendre = %2d" % (a, pow(a, 6, 13), -1 if pow(a, 6, 13) == 12 else pow(a, 6, 13)))
```

输出：

```
a= 1: a^6 mod 13 =  1 -> Legendre =  1
a= 2: a^6 mod 13 = 12 -> Legendre = -1
a= 3: a^6 mod 13 =  1 -> Legendre =  1
a= 4: a^6 mod 13 =  1 -> Legendre =  1
a= 9: a^6 mod 13 =  1 -> Legendre =  1
a=10: a^6 mod 13 =  1 -> Legendre =  1
a=12: a^6 mod 13 =  1 -> Legendre =  1
```

与平方表逐行对上：判出 +1 的恰是 $\{1,3,4,9,10,12\}$，判出 −1 的恰是非剩余。

### 2.2 Legendre 符号

**它是干嘛的**：Legendre 符号 $\left(\frac{a}{p}\right)$ 就是欧拉判据的记号：+1 表示有根、−1 表示没根、0 表示 p 整除 a。它把"开不开得方"变成一个可以写进公式、可以代入运算的量。

```python
def legendre(a, p):
    """p 奇素数：1 有根 / -1 无根 / 0 p 整除 a"""
    r = pow(a % p, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

bad = 0
for p in (13, 101, 10007):
    for a in range(-20, 200):
        if legendre(a, p) != sympy.legendre_symbol(a, p):
            bad += 1
print("legendre 手写 vs sympy 对拍不一致数:", bad)

p = 10007
ok = all(legendre(a, p) * legendre(b, p) == legendre(a * b, p)
         for a in range(2, 40) for b in range(2, 40))
print("(a/p)(b/p) == (ab/p) 全部成立:", ok)
```

输出：

```
legendre 手写 vs sympy 对拍不一致数: 0
(a/p)(b/p) == (ab/p) 全部成立: True
```

==乘法性 $\left(\frac{a}{p}\right)\left(\frac{b}{p}\right) = \left(\frac{ab}{p}\right)$ 是手算的主力==：判断一个数是否剩余，可以拆因子逐个看。两个常用特例也由乘法性推出：

> [!info]- 两个手算特例
> $\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}$：p ≡ 1 (mod 4) 时 −1 是剩余，p ≡ 3 (mod 4) 时不是（2.3 正要用它）。$\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}$：p ≡ ±1 (mod 8) 时 2 是剩余，p ≡ ±3 (mod 8) 时不是——10007 mod 8 = 7，所以 $\left(\frac{2}{10007}\right) = 1$，与 2.5 节输出一致。

### 2.3 开方捷径：p ≡ 3 mod 4

判定之后是求根。p ≡ 3 (mod 4) 时有一条一行公式：若 a 是二次剩余，

$$r = a^{\frac{p+1}{4}} \pmod p \tag{2.2}$$

推导一行：设 $a \equiv r_0^2$，则 $a^{\frac{p+1}{4}} = r_0^{p+1} = r_0^2 \cdot r_0^{p-1} \equiv r_0 \pmod p$，最后一步是费马小定理（[[09-密码学基础#2.3 费马小定理与欧拉定理|09 章 2.3]]）。

```python
p = 10007                       # p mod 4 = 3
print("p = 10007, p mod 4 =", p % 4)
a = pow(1234, 2, p)             # 已知一个根，反造一个二次剩余
print("a = 1234^2 mod 10007 =", a)
r = pow(a, (p + 1) // 4, p)
print("r = a^((p+1)/4) mod p =", r, " 另一个根 =", p - r)
print("验算 r^2 mod p =", r * r % p)

a_bad = next(x for x in range(2, p) if legendre(x, p) == -1)
r_bad = pow(a_bad, (p + 1) // 4, p)
print("非剩余 a =", a_bad, " 公式输出 =", r_bad, " r^2 mod p =", r_bad * r_bad % p)
```

输出：

```

非剩余 a = 5  公式输出 = 794  r^2 mod p = 10002
```

公式对每个二次剩余给出 ±r 两个根；a 非剩余时公式照样输出一个数，但它什么都不是（794 的平方是 10002，不是 5）。

> [!warning] 先判剩余再开方
> 式 (2.2) 的前提是 a 确实是二次剩余。拿到 c 要开方（解 $m^2 \equiv c$）时，==先用 Legendre 符号判一次==：判出 −1 就没有根，别把公式的输出当根用。判出 +1 才开方，两个根 $r$ 与 $p-r$ 都是解。

这条捷径是 CTF 里出现频率最高的开方写法：==出题人选 p ≡ 3 (mod 4) 的素数，就是让解密方（你，拿到 p 之后）开方有现成公式==。p ≡ 1 (mod 4) 的情况见[[#2.5 Tonelli-Shanks：p ≡ 1 mod 4 的一般开方|2.5]]。

### 2.4 Jacobi 符号：推广到合数模

**它是干嘛的**：Legendre 符号只对奇素数模有定义；Jacobi 符号 $\left(\frac{a}{n}\right)$ 把定义推广到奇合数 n——按 n 的素因子分解取乘积。它的价值在**算得快**：不用分解 n，用二次互反律辗转相除就能算，连 n 的因子都不知道也能算。这个不对称（算它容易、反着推出因子难）是 Solovay–Strassen 一类素性检验和某些 CTF 构造题的依据。

```python
def jacobi(a, n):
    """Jacobi 符号 (a/n)，n 为奇正整数"""
    a %= n
    result = 1
    while a:
        while a % 2 == 0:
            a //= 2
            if n % 8 in (3, 5):       # (2/n) 部分：n ≡ ±3 (mod 8) 时变号
                result = -result
        a, n = n, a                   # 二次互反律
        if a % 4 == 3 and n % 4 == 3:
            result = -result
        a %= n
    return result if n == 1 else 0

bad = 0
for n in (15, 21, 45, 561, 10005):
    for a in range(-30, 300):
        if jacobi(a, n) != sympy.jacobi_symbol(a, n):
            bad += 1
print("jacobi 手写 vs sympy 对拍不一致数:", bad)
print("素数 p 上 Jacobi 与 Legendre 一致:",
      all(jacobi(a, 10007) == legendre(a, 10007) for a in range(1, 10007)))
```

输出：

```

素数 p 上 Jacobi 与 Legendre 一致: True
```

n 是奇素数时 Jacobi 就是 Legendre；n 是合数时，==Jacobi 等于 +1 不再代表"有根"==：

```python
n = 15
print("(2/15) =", jacobi(2, 15))
print("但 x^2 ≡ 2 (mod 15) 有解吗:", [x for x in range(15) if x * x % 15 == 2])
print("拆开看: (2/3) =", jacobi(2, 3), " (2/5) =", jacobi(2, 5),

```


$\left(\frac{2}{15}\right) = \left(\frac{2}{3}\right)\left(\frac{2}{5}\right) = (-1)(-1) = +1$，但 x² ≡ 2 (mod 15) 无解——乘积里两个 −1 相互抵消了。==合数模上判平方根是否存在，必须每个素因子分别判==，Jacobi 的 +1 只说明"偶数个非剩余因子"。

### 2.5 Tonelli-Shanks：p ≡ 1 mod 4 的一般开方

p ≡ 1 (mod 4) 时式 (2.2) 的指数 $\frac{p+1}{4}$ 不是整数，捷径失效，要用一般算法 **Tonelli-Shanks**。思路是：把 p−1 写成 $q \cdot 2^s$，找一个非剩余 z（欧拉判据随机找，期望两次命中），从 $z^q$ 出发逐层平方，一层层消掉根指数里 2 的幂，最后收敛出平方根。p ≡ 3 (mod 4) 时 s = 1，它退化成式 (2.2)；s 越大循环越多，但都在毫秒量级。实际做题直接用库：

```python
from sympy.ntheory.residue_ntheory import sqrt_mod

print("sqrt_mod(a, 10009, all_roots=True) =", roots)
print("验算:", [r * r % p == a for r in roots])
print("顺带: sqrt_mod(2, 10007, all_roots=True) =", sqrt_mod(2, 10007, all_roots=True),
      "（2 是 mod 10007 的剩余吗:", legendre(2, 10007) == 1, "）")
```

输出：

```

a = 2222^2 mod 10009 = 2847

顺带: sqrt_mod(2, 10007, all_roots=True) = [2641, 7366] （2 是 mod 10007 的剩余吗: True ）
```

`all_roots=True` 把 ±r 两个根都给出来。模合数 n = p·q 的开方（Rabin 体制解密的完整形态）= 模 p、模 q 各开一个根再 CRT 拼合（[[09-密码学基础#2.4 中国剩余定理|09 章 2.4]]），四个根——那是后续 Rabin/RSA 变体的内容，这里先掌握"模素数开方"这一个工具。

## 3. 原根与阶

### 3.1 元素的阶

**它是干嘛的**：元素的阶 $\text{ord}(g)$ 回答"g 自乘多少次第一次回到 1"。它是 $\{g, g^2, g^3, \dots\}$ 这串幂的最小周期，决定了 g 的幂能覆盖多少个数——3.2 会看到，阶恰好达到 $\varphi(p)$ 的元素有专门的用途。

```python
import sympy

def order(g, p):
    """g 在模 p 乘法群里的阶：g^k ≡ 1 的最小 k（k | p-1）"""
    n = p - 1
    o = n
    for q in sympy.primefactors(n):
        while o % q == 0 and pow(g, o // q, p) == 1:
            o //= q
    return o

print("mod 7 各元素的阶:")
for g in range(1, 7):
    print("  ord(%d) = %d   幂序列: %s" % (g, order(g, 7),
          [pow(g, k, 7) for k in range(1, order(g, 7) + 1)]))
print("n_order 对拍:", [sympy.n_order(g, 7) for g in range(1, 7)])
print("ord(g) 整除 p-1=6:", all(6 % order(g, 7) == 0 for g in range(1, 7)))
```

输出：

```
mod 7 各元素的阶:
  ord(1) = 1   幂序列: [1]
  ord(2) = 3   幂序列: [2, 4, 1]
  ord(3) = 6   幂序列: [3, 2, 6, 4, 5, 1]
  ord(4) = 3   幂序列: [4, 2, 1]
  ord(5) = 6   幂序列: [5, 4, 6, 2, 3, 1]
  ord(6) = 2   幂序列: [6, 1]
n_order 对拍: [1, 3, 6, 3, 6, 2]
ord(g) 整除 p-1=6: True
```

g 的幂全体构成一个循环群，群的大小是 $\varphi(p)$；==拉格朗日定理保证每个元素的阶整除群阶==，所以 mod 素数 p 下 $\text{ord}(g) \mid p-1$。这条结构性约束立刻给出一个高效判别：要验证 $\text{ord}(g) = p-1$，不必算出确切的阶，==只需对 p−1 的每个素因子 q 检查 $g^{(p-1)/q} \neq 1$==——若阶不足 p−1，它必整除某个 $(p-1)/q$，那项检查就会等于 1。上面的 `order` 函数和 3.3 的找原根都用这一条。

### 3.2 原根：一个扫遍全群的元素

**它是干嘛的**：原根（primitive root）是阶达到最大值 $\varphi(p)$ 的元素——它的幂从 $g^0 = 1$ 到 $g^{p-2}$ 把 1..p−1 **每个数恰好取到一遍**。原根是乘法群的生成元：整个群用它一个元素的幂就能写出来，模 p 的乘法于是可以换成模 p 的指数来做。

```python
g = 3
print("3 的幂 mod 7:", [pow(g, k, 7) for k in range(0, 6)])
g = 2
print("2 的幂 mod 7:", [pow(g, k, 7) for k in range(0, 6)])
print("mod 7 的原根:", [x for x in range(1, 7) if order(x, 7) == 6], " 共 phi(6) =", sympy.totient(6), "个")
```

输出：

```
3 的幂 mod 7: [1, 3, 2, 6, 4, 5]
2 的幂 mod 7: [1, 2, 4, 1, 2, 4] （只在 {1,2,4} 打转）
mod 7 的原根: [3, 5]  共 phi(6) = 2 个
```

mod 7 的 3、5 是原根（阶 6），2 只能扫到 $\{1,2,4\}$（阶 3，非原根）。原根个数为 $\varphi(p-1)$：模 7 有 $\varphi(6) = 2$ 个。素数必有原根；一般地，==只有 $n = 1, 2, 4, p^k, 2p^k$ 这几种形状的数才有原根==，其余（如 15、8、561）没有。

### 3.3 找原根：分解 p-1，逐个排除

3.1 的判别直接就是找法：从 2 起逐个试 g，对 p−1 的每个素因子 q 检查 $g^{(p-1)/q} \neq 1$，全过即原根：

```python
from sympy.ntheory.residue_ntheory import primitive_root

def find_primitive_root(p):
    factors = sympy.primefactors(p - 1)
    for g in range(2, p):
        if all(pow(g, (p - 1) // q, p) != 1 for q in factors):
            return g

print("找原根（手写）:")
for p in (7, 101, 10007, 998244353):
    g = find_primitive_root(p)
    print("  p = %-10d 原根 = %-4d   sympy = %-4s   一致 = %s"
          % (p, g, primitive_root(p), g == primitive_root(p)))

print("\n几个大素数的最小原根:")
for p in (2**31 - 1, 2**61 - 1, 10**9 + 7):
    print("  p = %-12d 最小原根 = %d" % (p, find_primitive_root(p)))
```

输出：

```

  p = 101        原根 = 2      sympy = 2      一致 = True
  p = 10007      原根 = 5      sympy = 5      一致 = True
  p = 998244353  原根 = 3      sympy = 3      一致 = True

  p = 2147483647   最小原根 = 7
  p = 2305843009213693951 最小原根 = 37
  p = 1000000007   最小原根 = 5
```

> [!info]- 关于找原根的成本
> 成本几乎全在**分解 p−1**（检验本身每个候选只要 len(因子) 次快速幂）。p−1 的因子分解不出来，就没法做这套检验——所以构造题里常用已知结构的素数：998244353 是 NTT 常用模数，p−1 = 2²³ × 7 × 17，原根 3 是公开常识；$2^{31}-1$、$2^{61}-1$ 是梅森素数。另一个经验事实：最小原根通常极小（上表 5、7、37），从小往大试几十个内必命中。

**RSA 不需要原根，DH/ElGamal 需要**——一句区分：RSA 只做固定指数的乘方运算，$m^e$ 不需要任何生成元；Diffie-Hellman、ElGamal 一类体制把 $g^x$ 当作"由指数 x 唯一决定的公开坐标"来工作，g 必须扫过足够大的群（通常取原根或大阶元素），而==从 $g^x$ 反推 x 正是下一节的离散对数问题==。

## 4. 离散对数：从暴力到大步小步

### 4.1 定义与暴力

**它是干嘛的**：离散对数（DLP）是 3.2 那串幂的反查：已知 g 和 $h = g^x \bmod p$，求指数 x。普通对数问"10 的几次方等于 1000"，离散对数问"$g$ 的几次方（模 p）等于 $h$"。==它的困难性是 DH/ElGamal 一类体制的安全根基==——g、h、p 全公开，x（私钥）就是算不出来。

最直接的是从 1 开始乘 g 逐个比对，O(p)：

```python
def dlog_brute(g, h, p):
    e, x = 1, 0
    while e != h:
        e = e * g % p
        x += 1
    return x
```

p 到 $10^{12}$ 就是 $10^{12}$ 次乘法，纯 Python 起步按天算——需要一个更好的算法。

### 4.2 BSGS：大步小步，空间换时间

**它是干嘛的**：BSGS（baby-step giant-step，大步小步）把 O(p) 压到 $O(\sqrt{p})$：把待求指数 x 拆成两段 $x = i \cdot m + j$（m ≈ $\sqrt{\text{ord}(g)}$），j 段（j < m）的所有取值 $g^j$ 预先存进字典，i 段每次大步跨 m——==用 $\sqrt{p}$ 的内存把 $\sqrt{p}$ 次乘法换成了 $\sqrt{p}$ 次查表==。

$$x = i \cdot m + j, \qquad 0 \le j < m = \lceil\sqrt{\text{ord}(g)}\rceil \tag{4.1}$$

方程两边同除 $g^{im}$（即乘 $g^{-im}$）：

$$h \cdot g^{-im} \equiv g^{j} \pmod p \tag{4.2}$$

左边只有 i 种取值、右边只有 j 种取值，两边各 $\sqrt{\text{ord}}$ 次——找相等就是查字典：

```python
from math import isqrt

def bsgs(g, h, p, order):
    """解 g^x ≡ h (mod p)，要求传入 g 的阶 order"""
    m = isqrt(order) + 1
    table = {}
    e = 1
    for j in range(m):                # 小步：g^j, j < m
        if e not in table:
            table[e] = j
        e = e * g % p
    c = pow(g, -m, p)                 # g^(-m)（Python 3.8+ 负指数即逆元）
    gamma = h
    for i in range(m + 1):            # 大步：h * g^(-im)
        if gamma in table:
            return i * m + table[gamma]
        gamma = gamma * c % p
    return None
```

同一道小题三法对照（p = 1000003，原根 g = 2，真解 x = 654321）：

```python
import time

```

> `sympy.discrete_log(n, a, b)` 解 $b^x \equiv a \pmod n$——注意参数顺序，a 是目标 h、b 是底 g，==写反解出来的不是同一个 x==。它能自动选朴素/BSGS/Pollard rho/PH 等路径，传 `order=` 参数可跳过求阶（见 4.3 的用法与坑）。

### 4.3 Pollard rho 与 Pohlig-Hellman

**Pollard rho**（概念两句）：同样期望 $O(\sqrt{\text{ord}})$ 时间，但只存常数个量——把指数序列按伪随机规则迭代，让它尽快进入循环，用寻找碰撞（生日悖论，期望 $\sqrt{\text{ord}}$ 步）代替存表。内存从 GB 量级降到字节量级，速度与 BSGS 同阶；细节本库后续章节展开。

**Pohlig-Hellman**（概念一句）：若 g 的阶是光滑的（素因子都很小），阶被因子拆开后，DLP 变成每个小因子上一道微型 DLP，再用 CRT（[[09-密码学基础#2.4 中国剩余定理|09 章 2.4]]）拼回 x——==一道 $2^{60}$ 阶的难题瞬间变成 60 道二选一==。这就是 1.4 强素数伏笔的兑现处：p−1 不光滑，PH 才无用武之地。

光滑阶有一个特别干净的特例——阶为 $2^e$ 时，x 的二进制位可以一位一位问出来：

```python
import random
c = 3
while not sympy.isprime(c * 2**60 + 1):     # 找 p = c·2^60 + 1 型素数
    c += 2
p3 = c * 2**60 + 1
print("p3 = %d * 2^60 + 1 = %d (%d 位, 素数)" % (c, p3, len(str(p3))))

random.seed(2024)
while True:
    hh = random.randrange(2, p3)
    g3 = pow(hh, c, p3)                     # 阶整除 2^60
    if pow(g3, 2**59, p3) != 1:             # 不是 2^59 阶 -> 恰为 2^60 阶
        break
x3 = random.randrange(0, 2**60)
h3 = pow(g3, x3, p3)
print("g3 的阶 = 2^60, 真解 x = %d" % x3)

def dlog_2smooth(g, h, p, e):
    """g 的阶为 2^e 时解 g^x = h (mod p)：逐位确定 x 的二进制位"""
    x = 0
    for k in range(e):
        hk = h * pow(pow(g, x, p), -1, p) % p   # 消掉已定低位后的目标
        if pow(hk, 2 ** (e - 1 - k), p) != 1:   # 判第 k 位是 0 还是 1
            x += 2 ** k
    return x

t0 = time.perf_counter()
got3 = dlog_2smooth(g3, h3, p3, 60)
print("逐位法(2^60 特例): x = %d, 验算 g^x == h: %s, 耗时 %.1f ms"
      % (got3, pow(g3, got3, p3) == h3, (time.perf_counter() - t0) * 1000))
```

输出：

```
p3 = 31 * 2^60 + 1 = 35740566642812256257 (20 位, 素数)
g3 的阶 = 2^60, 真解 x = 700402945330441788
逐位法(2^60 特例): x = 700402945330441788, 验算 g^x == h: True, 耗时 0.4 ms
```

原理一句话：$\text{ord}(g) = 2^{60}$ 时，$h_k = h \cdot g^{-x_{\text{已知}}}$ 的 $2^{59}$ 次幂只会是 1 或 −1，结果直接给出 x 的当前二进制位；定住低位再问下一位，60 位共 60 问。独立工具复核同一道题（gp 的 `znlog`）：

```bash

```

```

```

对照面：同样规模、但阶是素数（不光滑）的群。取安全素数对 q 与 2q+1（q ≈ $10^{12}$，12 位），在阶恰为 q 的子群里解同尺寸的 DLP——没有小因子可拆，sympy 退化为 BSGS：

```python
q = 10**12 - 1
while not (q % 2 == 1 and sympy.isprime(q) and sympy.isprime(2 * q + 1)):
    q -= 2                                  # 往下找安全素数对
p4 = 2 * q + 1
g4 = pow(primitive_root(p4), 2, p4)         # 原根平方 -> 阶恰为 q 的元素
x4 = random.randrange(0, q)
h4 = pow(g4, x4, p4)
print("对照: p4 = 2*%d+1, 子群阶 q 是 %d 位素数" % (q, len(str(q))))
t0 = time.perf_counter()
got4 = discrete_log(p4, h4, g4, order=q)
print("sympy discrete_log(order=q, 素数阶只能 BSGS): 正确 = %s, 耗时 %.1f ms"
      % (got4 == x4, (time.perf_counter() - t0) * 1000))
```

输出：

```
对照: p4 = 2*999999999863+1, 子群阶 q 是 12 位素数
sympy discrete_log(order=q, 素数阶只能 BSGS): 正确 = True, 耗时 355.7 ms
```

把两个输出放在一起读：==60 比特的光滑阶 0.4 ms，40 比特的素数阶 355.7 ms==——更小的那个反而慢近千倍，差距全部来自"阶能不能拆"。这正是 Diffie-Hellman 参数要选强素数的原因，也是 1.4 强素数一句伏笔的着落点。

> [!info]- sympy 1.14 的一个坑
> `discrete_log(p3, h3, g3, order=2**60)` 会直接抛 `UnboundLocalError`——1.14 的 Pohlig-Hellman 分支对 2 幂阶有一个未绑定局部变量的 bug。光滑阶的题要么自己写（如上面的逐位法），要么交给 gp 的 `znlog` / sage 的 `discrete_log`，两者都正常走 PH。

| ---- | ---- | ---- | ---- | ---- |
| 下一个素数 | `nextprime(10**9)` | `next_prime(10**9)` | `nextprime(10^9)` | `next_prime(10^9)` |
| 素性检验 | `isprime(3215031751)` | `is_prime(3215031751)` | `isprime(3215031751)` | `is_prime(3215031751)` |

## 6. 常见问题

| 现象 | 原因与解决 |
| ---- | ---- |
| MR 用底数 [2,3,5,7] 把 3215031751 判成素数 | 这组底数的确定性界限恰好是 3215031751，到边界即失效（[[#1.4 确定性底数与素数生成\|1.4]]）；加一个底数（如 11）就判出合数，或直接用 `sympy.isprime` |
| 费马检验把 561 判成素数 | 561 是卡迈克尔数，对互素底数全通过是它的定义行为（[[#1.2 费马检验：快，但会被卡迈克尔数骗\|1.2]]）；素性判定一律用 MR，费马检验只适合做初筛 |
| 算出 Jacobi 符号 +1 就当"有平方根"去开方 | 合数模上 Jacobi = +1 不代表有解：(2/15) = 1 但 x² ≡ 2 (mod 15) 无解（[[#2.4 Jacobi 符号：推广到合数模\|2.4]]）；判根是否存在要按素因子分别用 Legendre |
| p ≡ 3 (mod 4) 开方公式算出的根验算不对 | a 不是二次剩余，公式输出无意义（[[#2.3 开方捷径：p ≡ 3 mod 4\|2.3]] 输出里的 794）；先用 Legendre 判 +1 再开方 |
| BSGS 的字典内存不够用 | 阶超过 10^16 后 √阶 10^8 项的字典到 GB 量级，2^60 阶就到 100 GB（[[#4.2 BSGS：大步小步，空间换时间\|4.2]]）；换 Pollard rho（常数内存），或先看阶是否光滑走 Pohlig-Hellman |
| `sympy.discrete_log(n, a, b)` 解出的 x 代回去不对 | 参数顺序搞反了：a 是目标 h、b 是底 g，解 b^x ≡ a；写反解的是另一个方程 |
| `discrete_log(..., order=2**60)` 报 UnboundLocalError | sympy 1.14 的 PH 分支对 2 幂阶的 bug（[[#4.3 Pollard rho 与 Pohlig-Hellman\|4.3]] 折叠框）；光滑阶自己写逐位法，或用 gp `znlog` / sage `discrete_log` |
| 素数阶大群上 `discrete_log` 长时间无输出 | 没有光滑结构可拆，退化为 BSGS/rho，需要 √q 步——运行时长本身就说明该换思路或换算法；先试 `factorint(order)` 看是否光滑 |
| gp 报 `not a function in function call: legendre` | gp 没有 legendre 函数（同名只剩勒让德多项式 `pollegendre`）；用 `kronecker(a, p)`，素数模时同值（[[#5. 工具对照表\|第 5 节]]） |
| Git Bash 里 `echo '...' \| gp` 的 `$`、引号被吞 | Git Bash 经 `wsl --` 传 shell 变量的已知问题；把 gp 命令写进 `.gp` 文件再 `gp -q 文件`，或像本章这样用 `printf '...\n' \| gp -q --default colors=no` |
| `sympy.primitive_root(15)` 返回 None 而不是报错 | 15 不在 1, 2, 4, p^k, 2p^k 之列，没有原根（[[#3.2 原根：一个扫遍全群的元素\|3.2]]）；sympy 用 None 表示"无"，调用后要判空 |
| 找原根极慢 | 成本在分解 p−1；因子分解不出来检验就无从做起（[[#3.3 找原根：分解 p-1，逐个排除\|3.3]]）；构造题优先用已知结构的素数（998244353、2^61−1 等的原根是公开常识） |
