## 1. 背包密码与低密度攻击

### 1.1 超递增背包：贪心可解

子集和问题：给 $n$ 个正整数 $w_1, \dots, w_n$ 和一个和 $s$，问是否存在 0/1 选择向量 $\varepsilon \in \{0,1\}^n$ 使

$$s \;=\; \sum_{i=1}^{n} \varepsilon_i\, w_i \tag{1.1}$$

一般情形是 NP 难的，但有一类例外可直接解：**超递增序列**——每一项都大于前面全部项之和（$w_i > \sum_{j<i} w_j$）。从最大权值往回装：$s$ 装得下 $w_n$ 就必选它（剩下的项加起来都不够填这个差额），减掉后继续，一轮扫完就是唯一解：

```python
# s1_mh.py —— 超递增序列的贪心求解
import random

random.seed(2026)
n = 16
w = []
S = 0
for i in range(n):
    step = random.randint(1, 2 ** i)        # 每步随机增长，保持超递增
    w.append(S + step)
    S += w[-1]
print("超递增序列（n = %d）" % n)
print("  w =", w)
print("  检查 w_i > sum(前面全部):", all(w[i] > sum(w[:i]) for i in range(1, n)))

def greedy(S, w):
    eps = [0] * len(w)
    rem = S
    for i in range(len(w) - 1, -1, -1):
        if rem >= w[i]:
            eps[i] = 1
            rem -= w[i]
    return eps, rem

msg = b"0k"
bits = [(msg[i >> 3] >> (7 - (i & 7))) & 1 for i in range(n)]
s_sum = sum(e * wi for e, wi in zip(bits, w))
eps, rem = greedy(s_sum, w)
print("  贪心求解: 未用容量 = %d, 位串一致 = %s" % (rem, eps == bits))
```

输出：

```
超递增序列（n = 16）
  w = [1, 3, 5, 13, 36, 90, 205, 415, 770, 1621, 3386, 7722, 15071, 36706, 66421, 164597]
  检查 w_i > sum(前面全部): True
  贪心求解: 未用容量 = 0, 位串一致 = True
```

贪心每一步的"必选"判断用到了超递增性：剩余和若装得下 $w_i$，则不选 $w_i$ 时剩余的全部项之和都不足补上这个差额，与最优解矛盾。==超递增是结构，结构就是密钥==——下一节把它藏起来。

### 1.2 Merkle-Hellman：模乘打乱

Merkle-Hellman 背包密码体制（1978）的想法：私钥就是一条超递增序列 $w$，公钥用模乘把它"打乱"：

- 取模数 $q > \sum w_i$ 和乘子 $r$（$\gcd(r, q) = 1$），这就是私钥 $(w, q, r)$；
- 公钥是 $b_i = r \cdot w_i \bmod q$。

加密把明文位串代进式 (1.1)，只是权值换成公钥：$s = \sum \varepsilon_i b_i \pmod q$。解密持有 $r^{-1}$：乘一下就回到超递增世界——$r^{-1} s \equiv \sum \varepsilon_i w_i \pmod q$，而这个和小于 $\sum w_i < q$，取模等于没取，贪心照用：

$$s \;=\; \sum_{i=1}^{n} \varepsilon_i\, b_i, \qquad s' = r^{-1} s \bmod q \;=\; \sum_{i=1}^{n} \varepsilon_i\, w_i \tag{1.2}$$

完整实现一副密钥并走一次往返：

```python
# s1_mh.py（续）—— Merkle-Hellman 密钥生成 / 加密 / 解密（greedy 沿用上一段）
import math

def mh_keygen(n, c, seed):
    """超递增序列 + 模乘打乱。c 控制位长增长速度，决定公钥密度（1.3）"""
    rng = random.Random(seed)
    w = [rng.randint(1, 2 ** 7)]            # 首项取大些：避免公钥里出现小系数关系（见常见问题）
    S = w[0]
    for i in range(1, n):
        step = rng.randint(1, max(2, int((c - 1) * S)))
        w.append(S + step)
        S += w[-1]
    q = S + rng.randint(1, S)
    r = rng.randrange(2, q - 1)
    while math.gcd(r, q) != 1:
        r = rng.randrange(2, q - 1)
    b = [r * wi % q for wi in w]
    return w, q, r, b

n = 64
w, q, r, b = mh_keygen(n, 1, seed=2026)     # c = 1：每步约长 1 比特，标准 MH 密度
print("Merkle-Hellman（n = 64, 增长步长 2^i）")
print("  私钥: q 的比特数 = %d, r = %d" % (q.bit_length(), r))
print("  sum(w) < q:", sum(w) < q)
print("  公钥 b 的最大值比特数 = %d   密度 d = n/log2(max b) = %.3f"
      % (max(b).bit_length(), n / max(b).bit_length()))

msg = b"k4ps4ck!"
bits = [(msg[i >> 3] >> (7 - (i & 7))) & 1 for i in range(n)]
s_ct = sum(e * bi for e, bi in zip(bits, b))
s_priv = s_ct * pow(r, -1, q) % q
eps, rem = greedy(s_priv, w)
print("  解密: 位串一致:", eps == bits)
```

输出：

```
Merkle-Hellman（n = 64, 增长步长 2^i）
  私钥: q 的比特数 = 69, r = 4962837132167321840
  sum(w) < q: True
  公钥 b 的最大值比特数 = 69   密度 d = n/log2(max b) = 0.928
  加密: s = 6856183106053821545362
  解密: 位串一致: True
```

公钥 $b$ 看起来是一堆无结构的随机大数——模乘把超递增的"每步翻倍"痕迹全抹掉了。持私钥一方一步 $r^{-1}$ 就还原；持公钥的一方只看到式 (1.1) 的一般子集和，教科书结论是它 NP 难。==但"一般情形难"不等于"每个实例都难"==：密度低的实例有另一条命。

### 1.3 密度：攻击可行性的刻度

$$d \;=\; \frac{n}{\log_2(\max_i b_i)} \tag{1.3}$$

分子是未知量的个数（0/1 向量的维数），分母是"一条方程提供的信息量"——权值的比特数。$d \approx 1$ 时未知量个数与已知比特数相当，解基本唯一但搜索空间没有多余约束；$d$ 越小，权值相对越大，==方程的"长度余量"越足==。上面的标准 MH（$c = 1$）密度 0.928：每步只长约 1 比特，$\max b \approx q \approx 2^{n}$。要造低密度的靶，让序列每步长约 $1/d$ 比特即可（`mh_keygen` 的参数 $c$ 干的就是这件事）。

### 1.4 LO 低密度攻击：单位阵加缩放尾列

Lagarias–Odlyzko（1985）的观察：把子集和写成格上的短向量。构造 $(n+1) \times (n+1)$ 的格，前 $n$ 行是单位阵，最后一行放"方程"：

$$B \;=\; \begin{pmatrix} 1 & & & & K b_1 \\ & \ddots & & & \vdots \\ & & 1 & & K b_n \\ 0 & \cdots & 0 & & K s \end{pmatrix} \tag{1.4}$$

$K$ 是缩放常数（取大于 $\sqrt{n}$ 即可）。做整系数组合 $\sum \varepsilon_i \cdot (\text{第 } i \text{ 行}) - (\text{最后一行})$，得到向量

$$\big(\varepsilon_1, \dots, \varepsilon_n,\;\; K(\textstyle\sum \varepsilon_i b_i - s)\big)$$

若 $\varepsilon$ 是真解，末位为 0，整条向量就是 $(\varepsilon \,|\, 0)$，范数 $\sqrt{\#\text{ones}} \le \sqrt{n}$。这个构造为什么指向短向量：末位是 $K$ 的倍数，$K > \sqrt n$ 时==任何不精确满足方程的组合，末位一项就把它顶到比目标长==——能和目标竞争的只剩"末位恰为 0"的向量，也就是子集和方程的精确解与整数关系；低密度下这些都不如目标短。跑一遍自造的低密度靶：

```python
# s2_lo_attack.py —— LO 攻击打穿自造 MH 靶（fpylll 沿用 C13 的用法；mh_keygen 同 1.2）
import math
from fpylll import IntegerMatrix, LLL

n = 64
w, q, r, b = mh_keygen(n, 6, seed=7)       # c = 6：每步长约 2.2 比特，密度压到 0.5 以下
msg = b"k4ps4ck!"
bits = [(msg[i >> 3] >> (7 - (i & 7))) & 1 for i in range(n)]
s_ct = sum(e * bi for e, bi in zip(bits, b))
dens = n / max(b).bit_length()
print("自造 MH 靶: n = %d, log2(max b) = %d, 密度 d = %.3f" % (n, max(b).bit_length(), dens))
print("明文 %r, 密文（背包和）s = %d" % (msg, s_ct))

K = 1 << 8
rows = []
for i in range(n):
    row = [0] * (n + 1)
    row[i] = 1
    row[n] = K * b[i]
    rows.append(row)
rows.append([0] * n + [K * s_ct])
print("LO 格: 维度 %d, |det| = K*s, det^(1/(n+1)) = 2^%.2f"
      % (n + 1, math.log2(K * s_ct) / (n + 1)))

A = IntegerMatrix.from_matrix(rows)
LLL.reduction(A)
out = [[A[i, j] for j in range(A.ncols)] for i in range(A.nrows)]
norms = sorted(math.sqrt(sum(x * x for x in row)) for row in out)
print("LLL 后各行范数（前 5）:", [round(v, 2) for v in norms[:5]])

for row in out:                             # 逐行提取 0/1 解并验算
    if row[-1] != 0:
        continue
    core = row[:n]
    for cand in (core, [-x for x in core]):  # LLL 可能返回取负后的目标
        if all(x in (0, 1) for x in cand):
            eps = cand
            if sum(e * bi for e, bi in zip(eps, b)) == s_ct:
                print("LO 攻击: 恢复成功, 位串与明文一致 =", eps == bits)
                break
```

输出：

```

明文 b'k4ps4ck!', 密文（背包和）s = 777972977330788350111994523918755555897528
LO 格: 维度 65, |det| = K*s, det^(1/(n+1)) = 2^2.26
LLL 后各行范数（前 5）: [5.48, 6.0, 6.4, 6.4, 6.56]
```

最短行范数 5.48 = $\sqrt{30}$，正是明文位串里 1 的个数——目标向量如预期成为第一行。0/1 位的提取必须逐行扫并验算 $\sum \varepsilon_i b_i = s$：LLL 输出的行序与行符号不固定（[[C13-格密码与LLL#3.4 四路对拍|C13 §3.4]]），目标不保证在第一行。

### 1.5 CJLOSS 与密度边界

Coster–Joux–LaMacchia–Odlyzko–Schnorr（1992）把临界密度从 LO 的 0.6403 提到 **0.9408**，改动只有一行：把"方程行"换成 $(1, 1, \dots, 1 \mid 2Ks)$、每行单位坐标加倍，使组合向量的前 $n$ 个坐标变成 $\pm 1$：

$$\sum \varepsilon_i (2e_i \mid 2K b_i) - (1, \dots, 1 \mid 2K s) \;=\; (2\varepsilon - 1 \mid 0) \tag{1.5}$$

目标是 $(-1,+1)$ 向量而不再是 $0/1$ 向量——它在格中"居中"，与典型间距的相对余量更大；提取时 $\varepsilon_i = (v_i + 1)/2$，且必须把整行取负后再试一次（LLL 返回目标取负的概率不低，取负后提取出的是"补码解"，验算必失败——这是本节打靶时踩到的真实坑，见常见问题）。

两种构造的成功率随密度怎么变，用 480 个自造 MH 公钥实例（$n = 40$，密度从 0.32 扫到 1.02）量一遍：

> [!warning] 高密度为什么打不动
> 密度 $d \to 1$ 时，$\max b \approx 2^n$、$s$ 也在 $2^n$ 量级，格的典型间距 $\det^{1/(n+1)}$ 与目标范数 $\sqrt{n}$ 落到同一量级——短向量不再孤立，"差一点"的假解（末位非零但很小、或另一组精确解）在数量上压过真解，LLL 返回的以假解为主。这不是调参能救的：**未知量比特数与方程信息量持平，信息就不够**。0/1 向量有 $2^n$ 个候选、方程只提供 $\log_2 \max b \approx n$ 比特约束，密度逼近 1 时解的存在性都开始变得偶然。看到密度 $\ge 0.95$ 的背包题，直接放弃低密度攻击，改查题目有没有别的口子。

> [!info]- 低密度攻击与"破 MH"是两条路
> LO/CJLOSS 打的是**任意**子集和实例，只需要公钥和 $s$；对 Merkle-Hellman 本身还有另一类攻击：从公钥 $b$ 里把超递增结构恢复出来（Shamir, 1982，对基本 MH 是多项式时间），连私钥一起拿走。CTF 里遇到背包题先算密度：低了用 LO/CJLOSS；接近 1 时想"这是不是标准 MH"——是，去找 Shamir 型的密钥恢复工具或题目自身的实现漏洞。多重 MH（多轮模乘迭代）与更高密度的变体各有专门分析，超出本章范围。

## 2. NTRU

### 2.1 参数与环上乘法

NTRU（Hoffstein–Pipher–Silverman, 1998）的舞台是多项式环

$$R \;=\; \mathbb{Z}[x] \,/\, (x^N - 1) \tag{2.1}$$

乘法是**循环卷积**：$(a * b)_k = \sum_{i + j \equiv k \ (\mathrm{mod}\ N)} a_i b_j$。参数三元组 $(N, p, q)$，$q \gg p$，取小素数或 2 的幂（教学参数 $N=107, p=3, q=64$；真实参数 $N \ge 439$，$q$ 是 2 的大幂）。

密钥生成：私钥是两条小系数多项式 $f, g$（系数取 $\{-1, 0, 1\}$），要求 $f$ 在模 $p$ 和模 $q$ 下都可逆，记逆元 $F_p, F_q$。公钥：

$$h \;=\; F_q * g \;\pmod q \tag{2.2}$$

加密：明文 $m$、随机盲化子 $r$ 都是小系数多项式，密文

$$e \;=\; p \cdot r * h + m \;\pmod q \tag{2.3}$$

解密：先用私钥卷一下——$f * e = p \cdot r * g + f * m \pmod q$，各项系数都很小，落在中心提升（把系数从 $[0, q)$ 映回 $(-q/2, q/2]$）不产生错误的借位，于是模 $q$ 提升后严格等于整数等式；再乘 $F_p$：

$$a = \mathrm{clift}(f * e \bmod q), \qquad m \;=\; F_p * a \;\pmod p \tag{2.4}$$

### 2.2 手写实现：加解密往返

```python
# s4_ntru_lib.py（核心部分）—— 卷积、中心提升、密钥生成与加解密
def conv(a, b, N):
    r = [0] * N                              # 循环卷积：x^N = 1
    for i in range(N):
        if a[i]:
            for j in range(N):
                r[(i + j) % N] += a[i] * b[j]
    return r

def conv_mod(a, b, N, m):
    return [v % m for v in conv(a, b, N)]

def clift(v, m):
    return [v0 - m if v0 > m // 2 else v0 for v0 in v]

def ntru_keygen(N, p, q, rng, df, dg):
    while True:                              # f 需在 mod p 与 mod q 下都可逆
        f = rand_trinary(rng, N, df, df - 1)
        g = rand_trinary(rng, N, dg, dg)
        Fp = inv_poly(f, N, p)               # 模素数 p：多项式扩展欧几里得
        Fq = inv_poly_2k(f, N, 6)            # 模 2^6 = q：mod 2 求逆后 Hensel 提升
        if Fp is not None and Fq is not None:
            return f, g, Fp, Fq

def ntru_encrypt(h, m, N, p, q, rng, dr):
    r = rand_trinary(rng, N, dr, dr)
    e = conv_mod(h, r, N, q)
    e = [(p * v) % q for v in e]
    return [(v + mv) % q for v, mv in zip(e, m)]

def ntru_decrypt(f, Fp, e, N, p, q):
    a = clift(conv_mod(f, e, N, q), q)
    return conv_mod(Fp, a, N, p)
```

模 $2^k$ 求逆的实现（先在 $\mathbb{F}_2$ 里扩展欧几里得，再用牛顿迭代逐级提升到 $2^k$）放在折叠框里；主流程用不到它的细节，只需要知道"不存在时重掷 $f$"。

> [!info]- 环上求逆的两个函数
> 模素数 $p$ 直接对 $x^N - 1$ 做扩展欧几里得（sympy 的 `Poly(…, modulus=p)` + `sympy.invert`）；模 $2^k$ 先求 mod 2 的逆，再用牛顿迭代提升：若 $f \cdot \mathrm{inv} \equiv 1 \pmod{2^j}$，令 $e = f\cdot\mathrm{inv} - 1$，则 $\mathrm{inv}' = \mathrm{inv} - \mathrm{inv}\cdot e$ 满足 $f\cdot\mathrm{inv}' = 1 - e^2 \equiv 1 \pmod{2^{j+1}}$：
>
> ```python
> def inv_poly_2k(f, N, k):
>     inv = inv_poly([c % 2 for c in f], N, 2)     # GF(2) 上的逆
>     if inv is None:
>         return None
>     mod = 2
>     while mod < (1 << k):
>         e = conv_mod(f, inv, N, 2 * mod)
>         e[0] = (e[0] - 1) % (2 * mod)            # 只有常数项减 1
>         corr = conv_mod(inv, e, N, 2 * mod)
>         inv = [(a - b) % (2 * mod) for a, b in zip(inv, corr)]
>         mod *= 2
>     return inv
> ```
>
> 两个易错点：$e$ 的定义里"减 1"只发生在常数项（单位元的其余系数是 0，不是全 1）；$N$ 为奇素数时 $x^N - 1$ 在 $\mathbb{F}_2$ 上分解为 $(x+1)\Phi_N$，$f$ 的系数和为奇数就能躲开 $x+1$ 因子，与 $\Phi_N$ 互素则靠重掷。

### 2.3 格攻击：从公钥 h 找回私钥

式 (2.2) 移项：$f * h \equiv g \pmod q$。==$f$ 和 $g$ 都是范数 $\sqrt{\#(f) + \#(g)}$ 的小系数向量——它们就是格里的短向量==。构造 $2N \times 2N$ 的格：

$$\begin{pmatrix} I & H \\ 0 & qI \end{pmatrix}, \qquad H[i][j] = h[(j - i) \bmod N] \tag{2.5}$$

组合 $(f \mid 0) \cdot B = (f \mid f*h \bmod q) = (f \mid g)$。LLL 约减后扫每一行，把前半段当私钥候选试解密：

```python
# s4_ntru_lib.py（攻击部分）—— 公钥格与恢复
def h_lattice(h, N, q):
    rows = []
    for i in range(N):
        row = [0] * (2 * N)
        row[i] = 1
        for j in range(N):
            row[N + j] = h[(j - i) % N]        # 方向见常见问题：使 f@H = h*f
        rows.append(row)
    for i in range(N):
        row = [0] * (2 * N)
        row[N + i] = q
        rows.append(row)
    return rows

def attack_ntru(N, p, q, seed, df, dg, dr):
    rng = random.Random(seed)
    f, g, Fp, Fq = ntru_keygen(N, p, q, rng, df, dg)
    h = conv_mod(Fq, g, N, q)
    m = rand_trinary(rng, N, N // 4, N // 4)
    e = ntru_encrypt(h, m, N, p, q, rng, dr)
    A = IntegerMatrix.from_matrix(h_lattice(h, N, q))
    LLL.reduction(A)
    for i in range(A.nrows):
        cand = [A[i, j] for j in range(N)]
        for sgn in (1, -1):                     # LLL 可能给出取负
            fc = [sgn * v for v in cand]
            Fpc = inv_poly(fc, N, p)
            if Fpc is None:
                continue
            if trin_eq(ntru_decrypt(fc, Fpc, e, N, p, q), m):
                rot = next((k for k in range(N)  # 与真值差 x^k 旋转（自造靶可查）
                            if fc == [f[(j - k) % N] for j in range(N)]
                            or fc == [-f[(j - k) % N] for j in range(N)]), None)
                return True, i, rot, fc
    return False, None, None, None
```

## 3. GGH 与 LWE（概念层）

这两个体制与 NTRU 同属格密码，结构各讲一段，攻击史一句带过；CTF 里出现时题目会给出全部参数，重点在识别结构。

### 3.1 GGH：好基解密，坏基公开

Goldreich–Goldwasser–Halevi（1997）把 CVP 做成公钥体制：私钥是一组好基 $B_{\mathrm{good}}$（短且接近正交），公钥是 $B_{\mathrm{bad}} = U B_{\mathrm{good}}$（$U$ 是 unimodular 矩阵，[[C13-格密码与LLL#1.1 好基与坏基|C13 §1.1]]）。加密把明文映射到格点 $v$、加小噪声 $e$ 发出 $c = v + e$；解密持好基做 Babai 最近平面（[[C13-格密码与LLL#5. Babai 最近平面：把 CVP 解出来|C13 §5]]），噪声小于半间距就找回 $v$。攻击面也直接对应：==拿到坏基的攻击者同样可以约减它==——好基若"太好"（范数与约减基差距不大），LLL/BKZ 从公钥就能算出等价私钥；历史上 Nguyen（1999）用已知明文构造的嵌入格破掉了 GGH 的全部挑战参数，这条"已知明文 + 嵌入"的路线与下一节 HNP 的格构造同源。

### 3.2 LWE：带噪声的线性方程组

Regev（2005）定义：给 $m$ 条方程

$$\mathbf{A}\,\mathbf{s} + \mathbf{e} \;\equiv\; \mathbf{b} \;\pmod q, \qquad e_i \xleftarrow{\$} \text{小范围} \tag{3.1}$$

$\mathbf{A}, \mathbf{b}$ 公开，$s$ 是密钥。没有噪声时高斯消元一步解出 $s$；==噪声让消元失效==——每消一行，误差项被系数放大一次，消到最后误差充满整个模空间。求解 LWE 的已知路线全是格的：把 $(\mathbf{A}, \mathbf{b})$ 排成"误差向量是最短向量"的嵌入格，用 BKZ 找。Regev 证明了 LWE 的平均难度归约到格上的最坏情形问题，这是它被 NIST 后量子标准采纳（Kyber/Dilithium 都建在 LWE 及其变体上）的原因。CTF 里 LWE 题的常见弱点是参数教学化（$q$ 小、$m$ 多、误差范围窄），把方程组直接交给嵌入格 + LLL 就能出解。

## 4. 截断 LCG 的格归约

[[C04-随机数攻防#6.3 截断输出：z3 求解|C04 §6.3]] 用 z3 解过"只拿高 16 位"的截断 LCG，并在折叠框里留了一句：观测少到 z3 吃力时，格归约是后手。现在回收这个伏笔。LCG 与参数沿用 C04：$m = 2^{32}$，$a = 1664525$，$c = 1013904223$（[[C04-随机数攻防#6. LCG 攻击|C04 §6]] 的递推式 (4.4)）。

### 4.1 状态线性化与消元

每个状态的高位已知、低位未知：

$$x_i \;=\; h_i \cdot 2^{L} + y_i, \qquad 0 \le y_i < 2^{L} \tag{4.1}$$

把式 (4.1) 代进递推 $x_{i+1} = a x_i + c \bmod m$，已知量归并成常数：

$$y_{i+1} \;\equiv\; a\, y_i + d_i \;\pmod m, \qquad d_i = \big((a\, h_i - h_{i+1}) \cdot 2^{L} + c\big) \bmod m \tag{4.2}$$

==$d_i$ 全部已知，未知的只剩每条输出的低位 $y_i$——一组"都很小"的未知数==。这里有一个一步到位的细节：不要把种子 $x_0$ 设成未知数再去解"带一个大未知数的方程组"——把种子消掉、让所有未知数同量级地小，格才有形状（常见问题里有反例）。

### 4.2 齐次格与 CVP

方程组 (4.2) 是非齐次的（有 $d_i$），解集是一个陪集，不是格。标准处理分两步：先解齐次格

$$L_0 \;=\; \{\,\mathbf{y} \in \mathbb{Z}^k \;:\; y_{i+1} \equiv a\, y_i \pmod m\,\} \tag{4.3}$$

基的形状与 [[C13-格密码与LLL#7.1 已知高位的数对：补全 p、q 转 CVP|C13 §7.1]] 的嵌入格同族——首行是齐次递推的"几何级数"解，下面每行是一个模数自由度：

$$\begin{pmatrix} 1 & a & a^2 & \cdots & a^{k-1} \\ & m & am & \cdots & a^{k-2}m \\ & & \ddots & \ddots & \vdots \\ & & & m & am \\ & & & & m \end{pmatrix}, \qquad \det = m^{k-1} \tag{4.4}$$

再取一个特解 $y^{p}$（令 $y^{p}_1 = 0$，按式 (4.2) 递推），真解 $y = y^{p} + v$（$v \in L_0$）。"每个 $y_i$ 落在 $[0, 2^L)$"等价于"$y^p + v$ 靠近中点向量"——CVP，目标是 $\big(2^{L-1} - y^{p}_i\big)_i$。解 CVP 用 fpylll 的精确 `CVP.closest_vector`（基先 LLL 约减），==拿到候选必须回代验算==：$y$ 全部落回范围、由 $x_1 = h_1 2^L + y_1$ 反推的种子能复现全部观测，两条都过才算数：

```python
# s5_lcg_lattice.py —— 截断 LCG：消元构造 + LLL + 精确 CVP
import random
from fpylll import IntegerMatrix, LLL, CVP

M32 = 2 ** 32
A32, C32 = 1664525, 1013904223

def lcg_lattice_attack(hi_bits, k_out, seed_true):
    Lb = 32 - hi_bits
    seq = lcg_seq(seed_true, A32, C32, M32, k_out + 2)   # lcg_seq 同 C04 §6：v = (a*v+c) % m
    obs = [v >> Lb for v in seq[:k_out]]
    d = [((A32 * obs[i] - obs[i + 1]) << Lb) + C32 for i in range(k_out - 1)]
    d = [v % M32 for v in d]

    rows = [[pow(A32, j, M32) for j in range(k_out)]]      # 式 (4.4) 的首行
    for j in range(k_out - 1):                              # 模数自由度
        row = [0] * k_out
        row[j + 1] = M32
        for i in range(j + 2, k_out):
            row[i] = M32 * pow(A32, i - j - 1, M32) % M32
        rows.append(row)
    A = IntegerMatrix.from_matrix(rows)
    LLL.reduction(A)

    yp = [0]
    for i in range(k_out - 1):
        yp.append((A32 * yp[-1] + d[i]) % M32)              # 特解
    target = [(1 << (Lb - 1)) - v for v in yp]              # CVP 目标
    v_hat = CVP.closest_vector(A, target)
    y = [yp[i] + v_hat[i] for i in range(k_out)]
    if not all(0 <= yi < (1 << Lb) for yi in y):            # 验算一：范围
        return False
    x1 = (obs[0] << Lb) + y[0]
    seed_rec = (x1 - C32) * pow(A32, -1, M32) % M32
    return lcg_seq(seed_rec, A32, C32, M32, k_out)[:k_out] == seq[:k_out]   # 验算二：复现
```

## 5. 隐数问题一瞥：HNP

### 5.1 标准格构造

隐数问题（Hidden Number Problem, Boneh–Venkatesan 2000）：给定若干对 $(a_i, b_i)$ 与模数 $q$，找 $x$ 使

$$t_i \;\equiv\; a_i\, x + b_i \;\pmod q, \qquad 0 \le t_i < T \ll q \tag{5.1}$$

所有 $t_i$ 都很小、都藏着同一个未知数 $x$——"隐"的就是它。[[C12-数字签名|C12]] 讲 nonce 偏差时用的是它的签名版：DSA 里 $k_i = s_i^{-1}(H_i + r_i x)$，若每次 nonce 的高位可预测（弱随机、截断、侧信道），低位 $t_i$ 就是式 (5.1) 的小余数，凑够签名就能把私钥 $x$ 拖出来；椭圆曲线上的 ECDSA 同构（[[C11-椭圆曲线与ECDLP|C11]]），攻击方法不变。

构造沿 §4 的同一条路——消元 + 齐次线格 + CVP。取 $c_i = a_i a_1^{-1} \bmod q$（$c_1 = 1$），未知数的公共部分缩成 $U = a_1 x$，格

$$L' \;=\; \left\langle\, (1, c_2, \dots, c_k),\;\; q\,e_2, \dots,\; q\,e_k \,\right\rangle, \qquad \det = q^{k-1} \tag{5.2}$$

的点是 $(U, c_2 U, \dots, c_k U)$ 的全部模 $q$ 平移。$t_i \in [0, T)$ 等价于"代表元靠近 $\mathrm{mid} - b_i$"（$\mathrm{mid} = T/2$），精确 CVP 解出 $U$，代回任一条方程得 $x$。可行条件照 §4.3 的算法：真解距离 $\sqrt{k} \cdot T/2$ 要明显小于典型间距 $\sqrt{k/(2\pi e)} \cdot q^{(k-1)/k}$，即

$$T \;<\; q^{(k-1)/k} \quad (\text{信息论下限：} k \cdot \log_2 T \ge \log_2 q) \tag{5.3}$$

### 5.2 靶：DSA 私钥与非随机 nonce

## 6. 格攻击方法论：什么时候想格

把本章与 [[C13-格密码与LLL|C13]]、[[C08-RSA攻击II|C08]] 的构造收成一张决策表。拿到题先过三问：**方程是不是（模意义下）线性的？未知量是不是比模小得多？模是已知还是待求？**三问的答案组合直接指向构造：

| 你看到的题面 | 三问的答案 | 格构造 | 出处 |
| ---- | ---- | ---- | ---- |
| $n$ 个 0/1 未知量 + 一个大整数和 | 线性、未知极小、模不存在 | 单位阵 + 缩放尾列（LO/CJLOSS），SVP | 本章 1.4–1.5 |
| 环上小系数乘法关系 $f * h \equiv g$ | 线性（卷积）、未知极小、模已知 | 卷积块格 $[I\ H;\, 0\ qI]$，SVP | 本章 2.3 |
| 一串带小余数的同余方程（截断 LCG 类） | 线性、余数小、模已知 | 消元 + 齐次格 + CVP | 本章 4 |
| 多条同余共享同一未知数、余数都小（HNP / nonce 偏差） | 线性、余数小、模已知 | 消元 + 线格 + CVP | 本章 5 |
| 模 $N$（或其因子）的多项式在小区间有根 | 非线性、根小、模已知 | Howgrave-Graham 格（Coppersmith） | [[C08-RSA攻击II#3. Howgrave-Graham 与手工 Coppersmith\|C08 §3]] |
| $p, q$ 的高位各知一部分，低位补全 | 线性、未知小、模已知 | 嵌入格 + CVP | [[C13-格密码与LLL#7.1 已知高位的数对：补全 p、q 转 CVP\|C13 §7.1]] |

两个前置分流：模未知时先把它求出来（差分 gcd，[[C04-随机数攻防#6.2 未知模数：差分 gcd|C04 §6.2]]）；非线性但根小，走 Coppersmith 而不是硬凑线性。构造定了之后，==每一格攻击都走同一条流水线：构造 → 估界 → 求解 → 验算==。估界用一笔账：目标向量范数（未知量的比特数）对比典型间距 $\det^{1/n}$ 与高斯启发式——差 2 比特以内就是赌博，差 10 比特以上才是攻击；本章 4.3 与 5.1 的两个临界（$2^{29.2}$ 与 $q^{(k-1)/k}$）都是这笔账的直接应用。

工具选择按维度与系数规模分级：

| 场景 | 工具 | 理由 |
| ---- | ---- | ---- |
| 2 维 | 高斯约简或小系数枚举 | 精确解，[[C13-格密码与LLL#6. 二维特例：高斯约简\|C13 §6]] |

| LLL 不够短 | fpylll `BKZ.reduction` 加 block size | 用时间换质量（[[C13-格密码与LLL#4. LLL 的近似保证与边界\|C13 §4]]） |

## 7. 选修：Shamir 秘密共享——拉格朗日插值的另一个用法

本章主线是格，这一节是选修：主题与格无关，数学只用 [[C02-数论进阶与原根|C02]] 的模 p 运算加一步多项式插值。放在本章作为应用视角的补充有两个理由：它是 CTF 里"分份恢复 flag"类题的标准模型；它与 §1 折叠框里破背包的 Shamir（1982）是同一位作者——Adi Shamir 1979 年提出的这个方案至今是秘密共享的事实标准。

### 7.1 门限方案与多项式分发

(k, n) 门限方案把秘密 s 分成 n 份（份额），满足两条：**任意 k 份能重构出 s**；**任何 k-1 份对 s 零信息**——不是算不动，是信息论意义上什么都不知道。k = 1 退化为人人可见，k = n 退化为全员到齐，一般取 2 ≤ k ≤ n。

构造在 mod p 的多项式上：p 取素数（大于秘密值与参与人数），随机取次数 k-1 的多项式，常数项即秘密：

$$f(x) \;=\; s + a_1 x + a_2 x^2 + \cdots + a_{k-1} x^{k-1} \pmod p, \qquad a_i \xleftarrow{\$} \mathbb{Z}_p \tag{7.1}$$

第 i 份份额是数对 $(x_i,\, f(x_i))$，$x_i$ 取互不相同的公开编号（如 1 到 n），$y_i = f(x_i)$ 私下分发。k-1 份为什么零信息：次数小于 k 的多项式被 k 个点唯一确定，而给定任意 k-1 个点与**任何一个**候选秘密 $s'$，都恰有一条次数 k-1、过这 k-1 个点且常数项为 $s'$ 的多项式——候选之间没有任何可区分性，缺少的那一份信息恰好对应 $\mathbb{Z}_p$ 个等可能的候选。

```python
# shamir_sss.py —— Shamir (k,n) 门限秘密共享：多项式分发 + 拉格朗日重构
import random

P = 2 ** 127 - 1                    # 模数取素数（梅森素数 2^127-1），全部运算 mod P

def make_shares(secret: int, k: int, n: int, rng):
    """秘密 s -> n 个份额 (x, f(x))。f 是 mod P 上次数 k-1 的多项式，
    常数项即秘密：f(x) = s + a1*x + ... + a_{k-1}*x^{k-1}，系数随机取"""
    assert 0 <= secret < P, "秘密必须落在 [0, P) 内，否则模运算会静默回绕"
    coeffs = [secret] + [rng.randrange(P) for _ in range(k - 1)]
    def f(x: int) -> int:
        return sum(c * pow(x, t, P) for t, c in enumerate(coeffs)) % P
    return [(x, f(x)) for x in range(1, n + 1)]

rng = random.Random(2026)
SECRET = int.from_bytes(b"flag{lagr4nge!}", "big")   # 15 字节 = 120 位 < 127 位

print("(k,n) = (3,5)，p = 2^127 - 1")
shares = make_shares(SECRET, k=3, n=5, rng=rng)
print("分发 5 份份额（x 从 1 到 5）：")
for x, y in shares:
    print("  x=%d  y = 0x%02x" % (x, y))
```

### 7.2 拉格朗日插值重构

拿到任意 k 个份额，重构就是插值求 $f(0)$。次数小于 k 的多项式被 k 个点唯一确定，把 $x = 0$ 代入拉格朗日公式：

$$f(0) \;=\; \sum_{i \in S} y_i \prod_{j \in S,\, j \ne i} \frac{x_j}{x_j - x_i} \pmod p \tag{7.2}$$

$S$ 是任取的 k 个份额编号集合。模 p 下没有除法，分母换成乘模逆（`pow(d, -1, p)`，[[C02-数论进阶与原根|C02]] 的扩展欧几里得），式 (7.2) 严格成立：

```python
# shamir_sss.py（续）—— 拉格朗日重构与门限验证
def combine(points, p=P):
    """拉格朗日插值重构 f(0)：points 为任意 k 个 (x, y)，顺序无关"""
    total = 0
    for xi, yi in points:
        num = den = 1
        for xj, _ in points:
            if xj != xi:
                num = num * (-xj) % p             # 分子累乘 (0 - xj)
                den = den * (xi - xj) % p         # 分母累乘 (xi - xj)
        total = (total + yi * num * pow(den, -1, p)) % p   # 除法 = 乘模逆
    return total

print("任意 3 份重构：")
for subset in [(1, 2, 3), (1, 3, 5), (2, 4, 5)]:
    pts = [shares[x - 1] for x in subset]
    rec = combine(pts)
    print("  份额 %s -> %s" % (subset,
          "与秘密一致" if rec == SECRET else "不一致"))

rec2 = combine(shares[:2])
print("只有 2 份（不足门限 k=3）重构：0x%02x" % rec2)
print("  等于秘密？", rec2 == SECRET, "—— 缺一份只能得到与秘密无关的随机值")

rec_bytes = combine(shares[1:4]).to_bytes(15, "big")
print("换一组（2,3,4）重构并转回字节:", rec_bytes)
```

输出（同一脚本的后续打印）：

```
  份额 (1, 2, 3) -> 与秘密一致
  份额 (1, 3, 5) -> 与秘密一致
  份额 (2, 4, 5) -> 与秘密一致

  等于秘密？ False —— 缺一份只能得到与秘密无关的随机值

```

三组不同的 3 份子集全部还原，2 份只能得到与秘密无关的随机值，转回字节立刻可读——门限方案的两条性质当场成立。这套"分发 + 插值"的两步，CTF 里常被拆开考：题面给份额，插值留给选手。

> [!warning] 四个高频坑
> **秘密必须小于 p**：超出后模运算静默回绕成 $s \bmod p$，重构出的"秘密"不等于原值——实现里的断言就是拦它；flag 这类字符串先 `int.from_bytes` 转整数，位数超过 p 的就换更大的素数或分块。**x 坐标要原样保留**：重构用的是分发时的 $x_i$，份额转存丢了编号，插值就错了对象。**p 必须是素数**：`pow(d, -1, p)` 在 p 非素或 $d \equiv 0$ 时抛 not invertible，两个份额的 x 相同也会让分母为零。**系数必须真随机**：$a_i$ 可预测时 k-1 份就凑得出整条多项式，门限保证作废，[[C04-随机数攻防|C04]] 的结论原样适用。

> [!info]- 式 (7.2) 为什么是对的
> 拉格朗日插值多项式 $L(x) = \sum_{i \in S} y_i\, \ell_i(x)$，其中 $\ell_i(x) = \prod_{j \in S, j \ne i} \frac{x - x_j}{x_i - x_j}$。每个基函数满足 $\ell_i(x_i) = 1$、$\ell_i(x_j) = 0\ (i \ne j)$，所以 L 过全部 k 个点；两条次数小于 k 的多项式若同时过这 k 个点，它们的差有 k 个根却次数小于 k，只能恒为零——插值唯一，故 $L \equiv f$，代 $x = 0$ 即式 (7.2)。除法换成乘模逆的可行性由 p 素与 x 互异保证。

### 7.3 CTF 形态与 CRT 变体

三种常见出现形态：

- **直接给份额**：题面给 n 条 $(x_i, y_i)$ 与素数 p，注明"至少 k 份可恢复"——式 (7.2) 一次插值就完。常见的坑在解析：x 与 y 混用十六进制和十进制、或份额按字符串给出需要先清洗。
- **逐字节共享**：秘密很长时对每个字节独立做 (k, n) 共享，p 取小素数（257 一类）。恢复时逐字节插值再拼回字节串；p 只比字节值域大一档，插值结果要检查范围。
- **作为链条一环**：重构出的不是 flag 而是下游密钥（RSA 私钥分片、门限签名的部分签名），插值只是第一步，后续环节接 [[C08-RSA攻击II|C08]] 或 [[C12-数字签名|C12]] 的攻击面；链式题的工时预期见 [[C20-密码学综合实战与赛事策略|C20]]。

插值不是唯一的路线。**Asmuth-Bloom**（1980）把同一门限需求搬到 CRT 上：选 $m_0 > s$，再取 n 个与 $m_0$ 互素且两两互素的模数 $m_1 < \cdots < m_n$，要求最小的 k 个之积 $M = m_1 \cdots m_k$ 大于 $m_0$ 乘最大的 k-1 个之积。份额是同余式 $y_i = (s + t\, m_0) \bmod m_i$（$t$ 随机、使括号小于 $M$）；重构时任意 k 条 $y_i \equiv s + t\,m_0 \pmod{m_i}$ 用 CRT 解出唯一解，再对 $m_0$ 取余得 s。与 Shamir 对比：重构走 CRT 而非插值；安全性论证从"多项式唯一性"换成"CRT 解的唯一区间"；两者都是信息论安全的门限方案。CTF 里 Asmuth-Bloom 出场率明显低于 Shamir，识别标志是题面给"一组互素模数 + 余数"而不是"平面上的点"。

| 现象 | 原因与解决 |
| ---- | ---- |
| LO 格 LLL 的第一行是 $(-2, 1, 0, \dots \mid 0)$ 这类小关系向量 | 公钥里藏着小系数关系（超递增序列首项太小，$b_1$ 恰为 $b_0$ 的整数倍）：目标不是第一行但仍在格里；逐行扫描加验算必能拿到，生成序列时首项取大可避免（[[#1.2 Merkle-Hellman：模乘打乱\|1.2]]） |
| 密度算出来不对，攻击该成功却没成功 | 分母写成 $\log_2(\sum b_i)$ 或平均值了：密度定义的分母是 $\log_2(\max_i b_i)$（[[#1.3 密度：攻击可行性的刻度\|1.3]]） |
| LO 格 LLL 输出的行提取不出 0/1 解 | 最后一行（方程行）漏掉时目标根本不在格里；缩放加错列（乘到单位阵上）会把目标自己也抬高。先手算 $\varepsilon = $ 真解（自造靶时）确认目标在格中，再查构造（[[#1.4 LO 低密度攻击：单位阵加缩放尾列\|1.4]]） |
| CJLOSS 提取的解验算总差一个"补" | LLL 返回了目标向量的取负：$(-1,+1)$ 行取负仍是 $(-1,+1)$ 行，提取出的是 $\varepsilon' = 1 - \varepsilon$，$\sum \varepsilon'_i b_i = \sum b_i - s \ne s$。两种符号都提取、都验算（[[#1.5 CJLOSS 与密度边界\|1.5]]） |
| NTRU 格攻击永远找不到能解密的行 | 卷积矩阵方向写反：要 $f$ 的系数对 $h[(j-i) \bmod N]$ 求和（即 $f@H = h*f$），写成 $h[(i-j) \bmod N]$ 得到的是相关而非卷积，LLL 照常输出短向量但都与 $(f, g)$ 无关，且不报错（[[#2.3 格攻击：从公钥 h 找回私钥\|2.3]]） |
| NTRU 恢复的"f"和答案里的不一样 | 差一个旋转 $x^k$ 或正负号都是对的：$x^k * f$ 是等价私钥，负号解出 $-m$，按三值编码取负即还原；以"能否解密"为准，不以逐位比对为准（[[#2.3 格攻击：从公钥 h 找回私钥\|2.3]]） |
| NTRU 靶用 $N=107$ 时 LLL 打不动 | 维度 214 的格、目标 7.3 与典型间距 8 几乎重合，LLL 的 $1.021^{2N}$ 质量不够；这不是 bug，是参数真的在屏障后——打靶换小 $N$，体会 $N \approx 60$ 的崩塌点（[[#2.4 维度是唯一的屏障\|2.4]]） |
| NTRU 解密偶发失败 | $f * (p \cdot r * g + m)$ 的系数超出中心提升范围，模 $q$ 时借位出错：降 $r$、$m$ 的非零系数密度，或加大 $q$；真实参数把失败概率压到可忽略（[[#2.2 手写实现：加解密往返\|2.2]]） |
| LCG 线性化套等比求和公式 $C_i = c\frac{a^i-1}{a-1}$ 报"不可逆" | $a - 1$ 与 $m = 2^{32}$ 不互素（$a$ 奇则 $a-1$ 偶）：直接递推累积 $A_i, C_i$，一行除法都不要（[[#4.1 状态线性化与消元\|4.1]]） |
| 截断 LCG 把种子设成未知数造格，LLL 输出的最短向量是 $(m, 0, \dots, 0)$ | "种子列"构造天然包含吸收向量：$q \cdot (\text{种子行})$ 与模数行组合出范数恰为 $m$ 的格点，比目标还短。把种子消掉、只留各输出的低位（[[#4.1 状态线性化与消元\|4.1]]） |
| 截断 LCG 手写 Babai 最近平面返回明显不是真解的点 | 最近平面是近似算法，此靶上它给出范数 $6 \times 10^9$ 的次优点，而真解距离只有 $6 \times 10^4$：解 CVP 用 fpylll 的 `CVP.closest_vector`（精确枚举），并且无论用什么求解器都保留"范围检查 + 复现检查"两道验算（[[#4.2 齐次格与 CVP\|4.2]]） |
| 截断 LCG 观测位数低于临界就全败，不知道加多少条数能救 | 临界能算：真解距离 $\sqrt{k} \cdot 2^{L-1}$ 对典型间距 $\sqrt{k/(2\pi e)} \cdot m^{(k-1)/k}$，条数 $k$ 增大时间距指数 $(k-1)/k$ 逼近 1，边界会推回去——先算账再选参数（[[#4.3 与 C04 对拍、成功边界\|4.3]]） |
| DSA 靶生成参数卡死 | 随机找 $p$ 再检查 $q \mid p-1$ 的概率是 $1/q$，等于永远等不到：按 $p = cq + 1$ 构造再验素性（[[#5.2 靶：DSA 私钥与非随机 nonce\|5.2]]） |
| HNP 靶解出的 $t_i$ 全是大数 | 化简时漏了 $s^{-1}$：$k = s^{-1}(H + rx)$，$A_i$ 是 $s^{-1} r$、$B_i$ 是 $s^{-1}H - k_{hi}T$，漏掉逆元后 $t_i$ 根本不是低位（[[#5.1 标准格构造\|5.1]]） |
| 拉格朗日重构的结果不等于秘密 | 秘密超出 $[0, p)$（模运算回绕）、x 坐标不是分发时的编号、或除法没换成乘模逆（[[#7.2 拉格朗日插值重构\|7.2]]） |
| `pow(d, -1, p)` 报 not invertible | p 非素数，或两个份额的 x 相同让分母 $\equiv 0$：门限方案要求素数模与互异 x（[[#7.1 门限方案与多项式分发\|7.1]]） |
| 格攻击"成功"输出一串大数 | 跳过了验算：范围检查（未知量落回界定范围）与复现检查（用恢复的密钥重演全部观测）是格攻击的收尾必做步，fpylll 不替你做（[[#4.3 与 C04 对拍、成功边界\|4.3]]） |
| 想加大 $K$ / 权重"让 LLL 更准"却没变化 | 权重的作用是量级对齐：把不同坐标的量纲拉到同一档（目标范数各坐标均衡），过量加权反而压垮真正的目标；先算目标各坐标的比特数再定权重（[[#1.4 LO 低密度攻击：单位阵加缩放尾列\|1.4]]、[[#4.2 齐次格与 CVP\|4.2]]） |

## 9. 配套练习与延伸阅读

> [!note] 实战任务
> 1. **背包边界复刻**：把 §1.5 的扫描改成 $n = 64$、只跑 CJLOSS，密度档取 $[0.85, 1.0]$，验证 0.9408 的临界在更大维度上的位置；把其中一档的失败实例捡出来，看 LLL 返回的假解长什么样（末位是否非零、范数与目标差多少）。
> 2. **NTRU 参数扫描**：把 §2.4 的扫描固定 $N = 53$、$q$ 从 64 提到 128、256，记录崩塌点移动方向；用 $\sqrt q$ 与目标范数的账解释移动原因。
> 3. **截断 LCG 换模数**：把 §4 的靶换成 Java 的 48 位参数（$m = 2^{48}$，$a = \mathtt{0x5DEECE66D}$，$c = \mathtt{0xB}$，见 [[C04-随机数攻防#7.1 Java Random：48 位 LCG\|C04 §7.1]]），重测"已知高位数 → 成功率"的边界表。
> 4. **HNP 变体**：把 §5.2 的 UNKNOWN 从 32 提到 48、64，每档用式 (5.3) 先算需要几条签名，再打靶核对；再加一档"nonce 低位已知、高位未知"（$t_i$ 定义换一头），改两行化简重解。
> 5. **平台练习**：[[01-练习平台索引|练习平台索引]] 的平台里用 "lattice"、"knapsack"、"NTRU"、"hidden number" 作关键词各找一题；CryptoHack（<https://cryptohack.org>）的 Lattices 分类从 Vector Networks 起做一遍，每题把"三问分流"（§6）的答案写进错题本。

配套练习：

1. 把 §1.4 的 LO 攻击改成输出全部候选行（不只第一行），统计 20 个低密度实例中"目标恰好是第一行"的比例，与 §1.5 表中 CJLOSS 同密度的成功率对照。
2. 给 §2.2 的 NTRU 实现加一段解密失败统计：把 $r$ 的非零系数从 5 对提到 10 对、20 对，记录 200 次往返的失败次数，对照 $q/p$ 比与中心提升余量的关系。
3. 把 §4 的格构造改成"种子列"版本（§8 的反例），在 $k=12$、高 16 位的靶上跑一遍，确认它失败并解释为什么消元构造救了它。
