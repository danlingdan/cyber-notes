# Cyber Notes

面向零基础新人的 CTF 阶梯式知识库：从 Linux 环境与 C 语言地基开始，一路走到逆向工程、PWN、Web 安全、密码学与 MISC 五个方向，再进入真题复盘与赛事策略。全部章节按统一模板写作，命令与代码均配输出，可以按顺序通读，也可以按目录速查。

## 学习路线

1. **打地基**：[[01-Linux环境与CTF实验环境搭建|01-通用基础]] 13 章覆盖环境搭建、C 与内存模型、汇编、ELF、Python 脚本、编码、网络协议等全赛道共用地基。
2. **选方向深入**：五个方向系列各自从导论章起步，按 order 编号顺序阅读即可，前置知识需要时会用双链指回。
3. **上实战**：`07-实战案例库` 收逐题 WriteUp（kmpc-prime-chain、llama-rpc-pwn 两篇完整解题记录）；各方向最后一章是综合实战与赛事策略，如 [[M20-MISC综合实战与赛事策略|M20]]、[[C20-密码学综合实战与赛事策略|C20]]、[[W20-Web赛事综合实战与策略|W20]]。

## 使用说明

> [!tip] 怎么读
> 左侧边栏按目录分组，组内按编号排序。每章开头的"章节信息"折叠块标注了所属方向、难度和前置章节；遇到双链可以直接跳转。命令都有配套输出，建议边读边在 Linux 环境里复现。

> [!note] 难度阶梯
> 各方向章节都按 L1 筑基 → L2 核心 → L3 进阶 → L4 高级 组织，零基础读者按编号顺序推进即可；已有基础的读者可以用各章"常见问题"和末章的知识地图（如 [[M20-MISC综合实战与赛事策略|M20]] 第 1 节）做查漏。
